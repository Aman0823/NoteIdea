## Purpose

规定 FR-2 的笔记浏览：文件树的数据来源、刷新时机、以及切换笔记时未落盘内容的处理。这一期只做「列出、打开、新建」，重命名 / 删除 / 拖动移动留待后续。

## ADDED Requirements

### Requirement: 工作区选择与恢复

主窗口的笔记展示以「当前工作区」为前提，不因后台已配置 vault 就在空白状态直接展示文件树。工作区选择入口始终位于窗口顶部；用户选择后才加载该文件夹下的 Markdown 笔记。已成功选择的工作区路径持久化，后续启动时自动恢复。

#### Scenario: 首次进入没有工作区
- **WHEN** 应用没有已保存的工作区路径
- **THEN** 主窗口显示空白欢迎态与顶部「选择工作区」按钮，不调用文件树读取，也不显示任何 md 文件内容

#### Scenario: 用户选择工作区
- **WHEN** 用户点击顶部「选择工作区」并选定一个有效文件夹
- **THEN** 保存该路径，加载该文件夹下的文件树，并进入笔记工作区

#### Scenario: 后续启动自动恢复
- **WHEN** 应用已有已保存且仍可访问的工作区路径
- **THEN** 主窗口自动恢复该工作区并加载文件树

#### Scenario: 已保存工作区失效
- **WHEN** 已保存路径不存在或不可用
- **THEN** 不显示旧工作区的文件树或笔记内容，显示失效原因与重新选择工作区入口

#### Scenario: 切换工作区
- **WHEN** 用户在顶部重新选择另一个工作区
- **THEN** 先清空当前打开笔记的展示状态，再加载新工作区的文件树，不残留旧工作区内容


文件树的唯一数据来源是 vault 目录本身，不是数据库。列出时必须跳过 `.noteidea/` 与 `assets/`。

#### Scenario: 正常列出
- **WHEN** vault 可用
- **THEN** 列出 vault 内全部 md 文件与含 md 的子目录，保持目录层级

#### Scenario: 跳过非笔记目录
- **WHEN** vault 内存在 `.noteidea/` 与 `assets/`
- **THEN** 这两个目录不出现在文件树里

#### Scenario: vault 不可用
- **WHEN** vault 路径失效或未选定
- **THEN** 显示为何不可用与选择文件夹的入口，不显示空文件树（空树会让用户以为笔记丢了）

#### Scenario: 某个子目录读取失败
- **WHEN** 某子目录因权限等原因读不到
- **THEN** 其余部分正常列出，该目录可见地标注读取失败，不中断整棵树

### Requirement: 文件树不自动跟随外部改动

这一期没有文件监听。外部新增、删除、重命名的文件不会自动反映到文件树，必须提供手动刷新，且这一限制对用户可见。

#### Scenario: 外部新增文件
- **WHEN** 用户在 VS Code 里新建了一篇笔记
- **THEN** 文件树在手动刷新前不显示它；不得声称自己是实时的

#### Scenario: 手动刷新
- **WHEN** 用户点击刷新
- **THEN** 重新列出当前 vault 内容

#### Scenario: 应用内新建文件后
- **WHEN** 通过应用新建一篇笔记
- **THEN** 文件树立即包含它并选中打开，无需手动刷新

### Requirement: 打开笔记与切换笔记

打开一篇笔记即把它的磁盘内容读入编辑缓冲。切换前必须先处理当前缓冲。

#### Scenario: 打开一篇笔记
- **WHEN** 用户点击文件树中的一篇笔记
- **THEN** 读入其磁盘内容作为编辑缓冲与同步基线

#### Scenario: 当前缓冲有未落盘变更
- **WHEN** 用户在当前笔记有未落盘变更时点击另一篇
- **THEN** 先落盘当前缓冲，成功后才加载目标笔记

#### Scenario: 落盘失败时不切换
- **WHEN** 切换前的落盘失败
- **THEN** 留在当前笔记并显示失败原因，不加载目标笔记

#### Scenario: 打开的文件已不存在
- **WHEN** 点击的文件在磁盘上已被外部删除
- **THEN** 可见地报告该文件已不存在并刷新文件树，不创建空文件顶替

### Requirement: 新建笔记

新建笔记经由 actor 的 create 操作，目标已存在时不得覆盖。

#### Scenario: 新建成功
- **WHEN** 用户新建一篇笔记且路径未被占用
- **THEN** 创建该文件、刷新文件树并打开它

#### Scenario: 同名文件已存在
- **WHEN** 目标路径上已有文件
- **THEN** 拒绝创建并提示已存在，不得覆盖原文件内容
