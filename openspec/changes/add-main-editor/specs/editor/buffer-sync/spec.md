## Purpose

规定编辑缓冲与磁盘之间的同步协议：编辑器提交什么、何时提交、基线冲突时如何 rebase 重投、以及撤销栈的边界（D20）。这层的失败方向只有一个可接受的形态——可见地失败，绝不静默丢掉用户敲进去的字。

## ADDED Requirements

### Requirement: 自动保存的时机

停止输入 800ms 后落盘。窗口失焦、切换笔记、退出应用时立即落盘，不等 debounce。复选框勾选、chip 上修改标记这类明确动作也立即落盘。

#### Scenario: 持续输入
- **WHEN** 用户连续打字未停顿超过 800ms
- **THEN** 不触发落盘，变更在缓冲中累积

#### Scenario: 停止输入
- **WHEN** 用户停止输入达 800ms
- **THEN** 把累积的变更作为一个 ChangeSet 提交给 actor

#### Scenario: 窗口失焦
- **WHEN** 主窗口失去焦点且缓冲中有未提交变更
- **THEN** 立即提交，不等 debounce 计时结束

#### Scenario: 勾选复选框
- **WHEN** 用户点击 GFM 复选框
- **THEN** 变更进入缓冲后立即提交，因为这是一次明确的动作而不是打字过程

#### Scenario: 缓冲无变更时的落盘触发
- **WHEN** 失焦或切换笔记，但缓冲中没有未提交变更
- **THEN** 不提交任何 ChangeSet，不产生空写入

### Requirement: 切换笔记与关窗前必须落盘成功

切换到另一篇笔记、或关闭窗口前，当前缓冲必须落盘成功。落盘失败时不得继续切换或关闭。

#### Scenario: 落盘成功后切换
- **WHEN** 用户点击另一篇笔记，当前缓冲落盘成功
- **THEN** 加载目标笔记，原缓冲释放

#### Scenario: 落盘失败
- **WHEN** 切换笔记前的落盘失败（权限、磁盘空间、基线冲突重投仍失败等）
- **THEN** 留在当前笔记，把失败原因显示给用户，不得切走——切走后这份缓冲失去承载它的界面，用户的输入会静默消失

#### Scenario: 退出应用时落盘失败
- **WHEN** 用户关闭窗口，落盘失败
- **THEN** 不关闭窗口，显示失败原因

### Requirement: 未确认变更与基线冲突重投

编辑器必须区分「已提交但未收到落盘确认」和「已确认落盘」的变更。基线冲突被拒绝时，把未确认变更在新基线上重映射后重投，不得丢弃。

#### Scenario: 提交后收到自己那批的确认
- **WHEN** actor 广播的变更正是本窗口提交的那一批
- **THEN** 将其标记为已确认并从未确认变更中移除，不重复应用

#### Scenario: 基线冲突被拒
- **WHEN** actor 因基线哈希不一致拒绝了本次提交
- **THEN** 先应用磁盘上的新内容作为新基线，把未确认变更重映射到新基线上，再重投；不得丢弃这些变更，也不得用磁盘内容整篇覆盖缓冲

#### Scenario: 重投仍然冲突
- **WHEN** 重映射后重投再次遇到基线冲突
- **THEN** 继续按同一流程重映射重投；连续失败达到上限后作为可见失败上报，缓冲内容保持不丢

#### Scenario: 远端变更与本地未确认变更改同一处
- **WHEN** 远端变更与本地未确认变更落在同一区间
- **THEN** 按重映射结果处理，两者都不得被静默丢弃；结果若无法自动确定则作为可见失败上报

### Requirement: 撤销栈只含本窗口自己的变更

每个窗口的撤销栈只包含该窗口用户操作产生的变更。远端广播来的变更参与重映射但不得进入本窗口撤销栈（D20）。

#### Scenario: 撤销自己的输入
- **WHEN** 用户在编辑器里按 Ctrl+Z
- **THEN** 撤销本窗口最近一次自己的编辑

#### Scenario: 远端变更不可被撤销
- **WHEN** 便签窗口勾选了某待办，该变更广播到主编辑器后，用户在主编辑器按 Ctrl+Z
- **THEN** 撤销的是本窗口自己的编辑，不得撤销那次勾选

#### Scenario: 远端变更到达后连续撤销
- **WHEN** 远端变更已应用到缓冲，用户连续按 Ctrl+Z 直到本窗口撤销栈为空
- **THEN** 停止撤销，远端变更保持不变，不得越过栈底去动它

### Requirement: 缓冲内容与磁盘不一致时不得静默取舍

任何时候发现缓冲与磁盘内容不一致，都不得静默选择其中一方覆盖另一方。

#### Scenario: 提交前发现磁盘已被外部改动
- **WHEN** 提交时基线哈希与磁盘不符
- **THEN** 走重映射重投流程，不得用缓冲全文覆盖磁盘，也不得用磁盘内容丢弃缓冲

#### Scenario: 重映射无法进行
- **WHEN** 磁盘内容变化过大导致重映射得不到有意义的结果
- **THEN** 作为可见失败上报并保留缓冲内容，让用户决定，不得自行取舍
