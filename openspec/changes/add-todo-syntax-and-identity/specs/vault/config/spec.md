## ADDED Requirements

### Requirement: 默认提醒时间配置项

配置须包含一个默认提醒时间，用于 3.2 的时间省略规则：用户只写日期不写时刻时以此补全。默认值为 09:00。

#### Scenario: 只写日期的提醒
- **WHEN** 待办含 `@2026-08-14` 而未指定时刻
- **THEN** 补全为该日期的默认提醒时间

#### Scenario: 相对日期不含时刻
- **WHEN** 待办含 `@tomorrow` 而未指定时刻
- **THEN** 补全为次日的默认提醒时间

#### Scenario: 配置中该项缺失或非法
- **WHEN** 配置文件中该项不存在，或取值不是合法的时刻
- **THEN** 使用 09:00 继续运行，不阻塞启动

#### Scenario: 用户修改默认提醒时间
- **WHEN** 用户改变该配置项
- **THEN** 仅影响此后新写入的省略式时间的求值，不得改写任何已存在的 md 内容
